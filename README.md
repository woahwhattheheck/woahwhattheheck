## Awards

### 2026 CCF Origin Cup: Open-Source Innovation Track

**Award winner** in the CCF Quantum Computing Programming Challenge, co-organized by Origin Quantum.

My contribution to Origin Quantum's `pyqpanda-algorithm` optimizes quantum support-vector regression (QSVR) by reusing training-kernel symmetry, reducing quantum-simulator evaluations from **n² to n(n + 1)/2**.

### Vesuvius Challenge

Accepted contributions to [ScrollPrize/villa](https://github.com/ScrollPrize/villa), the research software behind the effort to read ancient Herculaneum scrolls using 3D X-ray scans, computer vision, and machine learning.
