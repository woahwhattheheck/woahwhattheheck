# Trophy shelf

## Vesuvius Challenge

Merged contributions to [ScrollPrize/villa](https://github.com/ScrollPrize/villa), the open-source software used to help read ancient scrolls buried by the eruption of Mount Vesuvius.

- [**VC3D: Support Windows and WSL paths when attaching segments**](https://github.com/ScrollPrize/villa/pull/1849) — fixed local file navigation for network-style paths. Merged into `main`.
- [**Ink detection: Reject multi-page TIFF labels**](https://github.com/ScrollPrize/villa/pull/1987) — prevented the image-processing pipeline from mistaking TIFF pages for image data. Merged into `merge-ink-pipelines`.
